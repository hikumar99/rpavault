💡 Admin & Course Guide

⚙️ 1. Managing CMS Locally

  • Missing Buttons? Fixed! The top banner was covering the Save and Publish buttons. It has now been moved to the floating sidebar on the left.
  • Local Server: Ensure you are running npx decap-server to communicate with your local files instead of GitHub.
  • Saving & Publishing: Use the top bar in any entry to Save. Clicking Publish will commit changes directly to your local Git branch.
  • Closing the Editor: Click the Back arrow or the "X" button at the top-left of the editor to return to the collections view.

👨‍🏫 2. Managing Active Trainers

  • Single Active Trainer Display: To maintain a clean professional layout, course detail pages will only show one active trainer card at a time.
  • How to switch trainers: In the page metadata (front matter), you can define multiple trainers. The layout will automatically select and display only the first trainer in the list. Re-order the list items in Decap CMS to switch the displayed trainer.
  • Hiding the Trainer block: Toggle the "Show Trainers Section" setting to Off (or set show_trainers: false in YAML) to completely hide the block when you are not in a batch class or don't want to show any trainers.

🎓 3. Quick Facts & Pricing Card

  • Auto Geo-Pricing: Manual toggle buttons are removed. The system checks browser timezone and IP coordinates to show INR pricing for Indian visitors and USD pricing for US/Europe visitors automatically.
  • Tally Payment Integrations: Make sure the INR and USD tally urls are up-to-date in Decap CMS so students click through to correct payment checkouts.
