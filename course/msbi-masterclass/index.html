CURRICULUM

How the program is structured

Module 1 · Data Warehousing Foundations

Think in BI terms

  • OLTP vs OLAP, facts and dimensions
  • Star and snowflake schemas
  • Staging and loading strategies

Outcome: You can design a warehouse, not just query one.

Module 2 · SSIS (ETL)

The core of MSBI

  • Control flow and data flow design
  • Transformations, lookups, error handling
  • Package deployment and job scheduling

Outcome: You can build production ETL pipelines.

Module 3 · SSAS (Analysis)

Analytical modelling

  • Cubes, measures and hierarchies
  • Processing and browsing models

Outcome: You can serve fast analytical queries to business users.

Module 4 · SSRS (Reporting)

Deliver the insights

  • Report design, parameters and expressions
  • Subscriptions and deployment

Outcome: You can ship the reports businesses actually run on.
