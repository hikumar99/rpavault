CURRICULUM

How the program is structured

Phase 1 · Foundations

Classes 1–10

  • RPA concepts, UiPath Studio setup and interface
  • Variables, arguments, control flow and selectors
  • Data manipulation, Excel and DataTable automation
  • Debugging and error basics

Outcome: You can build reliable task automations on your own.

Phase 2 · Building Blocks

Classes 11–19

  • UI automation, web and desktop app automation
  • Email automation and PDF data extraction
  • Orchestrator: robots, assets, queues, schedules
  • Exception handling patterns

Outcome: You can automate real business processes end to end.

Phase 3 · Frameworks

Classes 20–25, 28–29

  • REFramework deep dive — the industry standard
  • Queue-based transactional processing
  • Code review habits, logging and deployment
  • Mini-project sprints

Outcome: You work the way RPA teams work in production.

Phase 4 · Power Automate + Agentic

Classes 26–27, 30–33

  • Power Automate cloud flows and approvals
  • Connecting UiPath with Microsoft ecosystem
  • Agentic automation: AI agents in real workflows
  • Capstone + interview preparation

Outcome: You leave with a portfolio, not just a certificate.
