Curriculum Roadmap

An Intensive Production Launchpad

An engineering curriculum engineered to take you from Python fundamentals to evaluating, fine-tuning, and deploying production-grade Generative AI systems.

Phase 01

Foundations & Classical ML

Weeks 1-2 • Python • NumPy • Pandas • Math • PyTorch
  • Python-to-LLM Foundation: Lists, dicts, OOP essentials, NumPy, Pandas data cleaning, vectors, cosine similarity, probability.
  • ML & Neural Networks: Tokenization, text cleaning, Bag-of-words, TF-IDF, logistic regression, accuracy, precision, recall, F1 score.
  • PyTorch Tensors: Perceptrons, autograd, forward-backward training loops, and spam/sentiment classifier lab.
Phase 02

Transformers & LLM Apps

Weeks 3-4 • Attention • Embeddings • Prompting • APIs • Tools
  • Transformers from First Principles: RNN limitations, Self-Attention, QKV mechanics, softmax, and multi-head attention.
  • Embeddings & Prompt Engineering: Semantic search, role/task/context constraints, few-shot prompts, structured outputs, safety & PII handling.
  • LLM Integration + FastAPI: Model families, context windows, JSON contracts, FastAPI endpoints, function & tool calling, validation, and retries.
Phase 03

RAG Quality & Evaluation

Weeks 5-6 • Vector DBs • Hybrid Retrieval • Evals • Observability
  • RAG Architecture: Document ingestion loaders, chunking strategies, metadata tagging, and FAISS/Chroma vector stores.
  • Advanced Retrieval: Hybrid keyword + dense retrieval, re-ranking models, grounded answer generation, and strict refusals.
  • Evals & Observability: Factuality, relevance, safety metrics, latency, cost tracking, evaluation dashboards, and contract testing.
Phase 04

Model Adaptation & Deployment

Weeks 7-8 • Fine-Tuning • PEFT / LoRA • Capstone • Docker
  • Model Adaptation: SFT vs RAG vs Prompting decision framework, instruction dataset preparation, PEFT and LoRA concepts.
  • Prompted vs Tuned Benchmarking: Comparative evaluation to measure cost, quality, and domain-specific accuracy.
  • Portfolio Capstone Deployment: Packaging the complete RAG assistant with FastAPI, Streamlit UI, Docker, and interview-ready demo scripts.
Portfolio Capstone Project

Enterprise Knowledge RAG Assistant

The final project integrates the complete 8-week path into a production-minded Generative AI system suitable for enterprise technical interviews, internal company pitches, or client proofs-of-concept.
